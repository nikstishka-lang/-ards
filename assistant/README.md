# Личный ассистент

Расписание, напоминания и планирование по жизни. Курс по маркетингу
ведётся отдельно, в `course/`.

## Файлы

| Файл | Что внутри |
|---|---|
| [goals.md](goals.md) | Колесо баланса: области, зачем каждая, что попадает в календарь |
| [week.md](week.md) | Каркас недели и арифметика времени |
| [money.md](money.md) | Долг, подушка, правила по деньгам |
| [routines.md](routines.md) | Какие напоминания настроены и когда приходят |
| [rules.md](rules.md) | Как ассистент себя ведёт. Правится свободно |

## Как это устроено

Не приложение и не бот. Это расписания на стороне Claude: в заданное
время запускается сессия, читает эти файлы, делает работу и
присылает push в приложение Claude на телефоне.

Работает без открытого чата и переживает перезапуски.

## Доступы

| | Статус |
|---|---|
| Репозиторий | есть |
| Google Drive | подключён |
| Веб-поиск | есть |
| **Google Calendar** | **не подключён** |
| Gmail | не подключён |

Календарь подключается на claude.ai/customize/connectors, после чего
нужно открыть **новую** сессию — расписание получает доступ только
к тем коннекторам, которые были у сессии в момент его создания.
Порядок: подключить → новая сессия → там ставить расписания.

## Статус

Черновик. Расписания ещё не заведены — ждут ответов по рабочим часам,
расписанию латины и времени подъёма.
